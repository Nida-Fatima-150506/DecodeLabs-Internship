# DecodeLabs Data Analytics Internship - Week 3 Project

This folder contains the project files and SQL analysis completed during Week 3 of the DecodeLabs Internship Program.

## 📁 Project Components
* **`week3_sql_analysis.ipynb`**: The Jupyter Notebook containing the full Python-SQL script using SQLite to pull data insights.
* **`Dataset for Data Analytics week 3.xlsx`**: The source transactional dataset containing 1,200 records.

## 🗄️ Core Database System Used
* **Engine:** Declarative SQL Structure via Python `sqlite3`
* **Primary Queries Executed:** `SELECT`, `WHERE`, `ORDER BY`, `GROUP BY`, and aggregations (`SUM`, `COUNT`, `AVG`).

## 📊 Summary of SQL Business Insights
* **Top Revenue Generator:** **Chair** ($195,620.11 across 178 orders)
* **Highest Order Volume:** **Printer** (181 distinct orders)
* **Preferred Customer Payment Method:** **Credit Card** ($263,847.63 total revenue)
* **Logistics Distribution:** The 1,200 transactions are distributed almost evenly across Cancelled, Delivered, Pending, Returned, and Shipped statuses.
