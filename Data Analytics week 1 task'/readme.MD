Project Name
Data Cleaning & Preparation
Objective of Project
The goal of this project was to clean a raw dataset and improve data integrity by handling:
• Missing values
• Duplicate records
• Incorrect formatting
• Data consistency issues

The project was completed using Microsoft Excel.
Tools Used
• Microsoft Excel
• Excel Formulas
• Conditional Formatting
• Data Validation
• Sorting & Filtering
• Freeze Panes
• Formatting Tools
Dataset Information
The dataset contained order and sales transaction records with columns such as:
• OrderID
• Date
• CustomerID
• Product
• Quantity
• UnitPrice
• ShippingAddress
• PaymentMethod
• OrderStatus
• TrackingNumber
• ItemsInCart
• CouponCode
• ReferralSource
• TotalPrice
Tasks Performed
1. Duplicate Detection & Verification
- Highlight Duplicates
- Remove Duplicates Tool
- Manual Verification

2. Missing Values Handling
- Filter Tool
- Blank Cell Identification
- Manual Filling
- Replaced blank CouponCode values with "No Coupon"

3. Date Formatting
- Standardized date format to DD/MM/YYYY

4. Sorting Operations
- Product
- OrderStatus
- CouponCode

5. Filtering Operations
- Shipped Orders
- Cancelled Orders

6. Formula Verification
- Formula Used: = Quantity × UnitPrice
- Created VerifiedTotal column
- Formula Example: =E2*F2

7. Conditional Formatting
- Highlighted values greater than 1500

8. Data Validation
Allowed Values:
- Shipped
- Delivered
- Pending
- Cancelled
- Returned

9. Freeze Top Row
- View → Freeze Top Row

10. Professional Formatting
- Bold Headings
- Center-Aligned Headers
- Borders Applied
- AutoFit Columns
- Consistent Font Sizes

Final Outcome
The raw dataset was successfully transformed into a clean, organized, validated, and professional dataset ready for further analytics and reporting.
