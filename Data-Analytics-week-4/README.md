# 📊 Data Analytics Project 4 - E-Commerce Sales Analysis

## 📌 Project Overview
This project analyzes an e-commerce dataset to extract business insights using Python data analysis and visualization techniques. The goal is to understand sales performance, customer behavior, payment methods, and marketing effectiveness.

---

## 📂 Dataset Description
The dataset contains 1200 orders with 15 features including:
- Product details
- Quantity and pricing
- Payment methods
- Order status
- Referral sources
- Dates and revenue

Two sheets are included:
- Raw dataset
- Cleaned dataset (used for analysis)

---

## 🛠 Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

---

## 📊 Key Analysis Performed
- Revenue by Product
- Payment Method Distribution
- Order Status Analysis
- Referral Source Revenue
- Monthly Sales Trend

---

## 📈 Key Insights

- Chair was the highest revenue-generating product.
- Online payments were the most preferred method.
- High number of cancelled and returned orders observed.
- Instagram and Email were top marketing channels.
- Sales peaked in June 2024, showing seasonal trend.

---

## 📌 Recommendations

- Focus on high-performing products like Chair, Printer, Laptop.
- Investigate high cancellation and return rates.
- Invest more in Instagram and Email marketing.
- Study peak sales months to improve strategy.
- Improve customer satisfaction to reduce returns.
