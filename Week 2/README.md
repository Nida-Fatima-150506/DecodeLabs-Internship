# DecodeLabs Data Analytics Internship - Week 2 Project

This repository contains the project files and analysis completed during Week 2 of the DecodeLabs Internship Program.

 📁 Project Files & Formats
* **`Dataset for Data Analytics.xlsx`**: The cleaned dataset containing retail transaction records.
* **`week2_data_analysis.ipynb`**: The Jupyter Notebook containing Python code for Exploratory Data Analysis (EDA) and summary statistics.
* **`product_sales_chart.png`**: Visual representation of the data showing "Total Orders by Product Type".

📊 Summary of Insights
* **Top Selling Product:** Printer (Highest volume of orders)
* **Least Selling Product:** Phone
